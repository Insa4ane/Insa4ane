## 🚀 Projects

### [X-Ray Analyzer](https://github.com/Insa4ane/Xray_Analyzer)
Chest X-ray pneumonia detection: a PyTorch CNN used as a feature extractor with an
XGBoost classifier on top. Exposed through a FastAPI REST API and a Streamlit UI,
fully containerized with Docker Compose and covered by unit tests.
*Educational project, not a diagnostic tool.*

### [Database in C++](https://github.com/Insa4ane/Database_in_cpp)
A multi-client database server built from scratch with UNIX sockets, `std::thread`
and mutex-based synchronization, with data persistence and optional per-record
password protection.

### [C++ / Python Vector Engine](https://github.com/Insa4ane/cpp-vector-engine)
A proof-of-concept vector search engine: a custom TCP server in C++17 integrated
with Python via `pybind11` and Sentence-Transformers for semantic search using
cosine similarity. Containerized with Docker.

### [Customer Churn Prediction](https://github.com/Insa4ane/CustomerChurnPrediction)
An end-to-end ML app predicting customer churn: scikit-learn pipeline (Random Forest),
FastAPI backend, Streamlit frontend, deployed with Docker Compose.
